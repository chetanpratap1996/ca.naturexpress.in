## 🚀 Key Modules & Capabilities

1. **1-Tap App Install (PWA)**:
   - Full Progressive Web App support across mobile (Android & iOS Safari) and desktop browsers.
   - Offline-capable service worker, app manifest, and instant 1-tap installation prompt with guidance modals.

2. **Client Collaboration Experience**:
   - Live tax filing progress and receipt acknowledgement downloads.
   - Banker loan packs and confidential document vault.
   - Direct UPI / NEFT fee payments and UTR submission workflow.
   - Plain-English document terminology tailored for business owners.

3. **CA Partner Cockpit**:
   - Statutory compliance calendar (GSTR-1, GSTR-3B, Tax Audits 3CD, Advance Tax, TDS).
   - Fee Release Gatekeeper (Pay-to-Release control before certified document access).
   - GSTR-2B vs Books reconciliation engine.
   - Tax notice center with scrutiny tracking.
   - ICAI Peer Review workpaper manager and digital signature (DSC) custody register.

## 🏁 Quickstart

```bash
# Clone the repository
git clone https://github.com/chetanpratap1996/ca.naturexpress.in.git
cd ca.naturexpress.in

# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```
